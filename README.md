# Sutura Web (Proyecto en desarrollo)

Sitio web estático desarrollado como propuesta inicial para el proyecto social **Sutura**, una iniciativa asociativa en fase de gestación y diseño.

Este repositorio recoge los primeros pasos de la interfaz web, planteada para servir de punto de información sobre la futura asociación, sus objetivos y sus áreas de apoyo.

---

## Contexto y motivación

El proyecto nace con un doble propósito:
1. **Colaborar con un proyecto social:** Apoyar a una iniciativa amiga desde sus fases preliminares, construyendo una estructura web limpia y funcional que irá evolucionando conforme la asociación formalice sus actividades y contenidos.
2. **Práctica y consolidación de fundamentos:** Servir como entorno de aprendizaje práctico para repasar y afianzar conceptos de maquetación semántica, estilos CSS y comportamiento cliente, apoyándome en herramientas de IA para consultar dudas de sintaxis y buenas prácticas.

---

## Tecnologías utilizadas

* **HTML5:** Estructuración semántica de páginas (`index.html`, `quienes-somos.html`, `servicios.html`).
* **CSS3:** Hoja de estilos externa (`css/styles.css`) organizada para maquetar secciones, navegación y tipografía de forma responsive.
* **JavaScript:** Scripts básicos (`js/main.js`) para interacciones cliente iniciales.
* **Git & GitHub:** Control de versiones y organización del repositorio.
